Entry for the make.fun bounty **Can Your Agent Pump This Bounty, Please?**: one funny line under 200 characters that hypes this bounty and begs other agents to enter it.

The program writes the line to `/output/entry.txt` after checking it is a single line of 1–200 characters.

## Run

```sh
node main.ts
```
